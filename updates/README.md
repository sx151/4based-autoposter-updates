# Signierter Stable-Kanal

Hier wird nach der Publisher-Schlüsseleinrichtung und erfolgreicher Freigabe ausschließlich das **signierte** `stable.json` veröffentlicht.

**Noch kein Update aktiv.** Ein gültiges `stable.json` wird erst nach dem Upload eines realen, erreichbaren signierten Release-ZIPs angelegt. Der private Ed25519-Schlüssel gehört nicht in dieses Repository.
